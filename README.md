# Fade Launcher

Fade Launcher is a personal, non-commercial Minecraft: Java Edition launcher. I am building it as a hobby project for myself, my brother and a few friends, to launch our own custom Minecraft client ("Fade Client") and a small modpack.

This repository is an information page only. The launcher is not distributed publicly and is not for sale.

## What it does
- Starts Minecraft: Java Edition with our custom client and mods.
- Lets us sign in with our own Microsoft accounts, so only people who own the game can play.

## How sign-in works
- Sign-in uses Microsoft's official OAuth login, in the browser. The launcher never sees or stores your Microsoft password.
- Only the tokens needed to keep you signed in are kept, on your own computer, and nothing is sent anywhere else.
- The launcher is only used by a handful of people I know personally.

## What it is not
- It is not a commercial product, and it has no ads, accounts or payments.
- It does not include or redistribute Minecraft's game files. The game is downloaded from Mojang's official servers by the owner of the account.
- It is not for cracked or offline accounts.
